# 📊 Excel for Data Analysts

A structured repository for learning, practicing, and revising **Microsoft Excel for Data Analyst roles**.

This repository covers Excel from fundamentals to advanced data analysis, including **formulas, data cleaning, Pivot Tables, Power Query, dashboards, and automation**.

---

## 🎯 Objective

The goal of this repository is to build practical Excel skills required for:

* Data Analysis
* Data Cleaning
* Business Reporting
* Dashboard Creation
* Data Visualization
* Interview Preparation
* Real-world Data Analyst Projects
